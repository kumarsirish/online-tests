# Coding Test for Students

## Objective
Build a small **Student Score Manager** program that can:
1. Add a student with a name and score
2. Update an existing student score
3. Remove a student
4. Show all students sorted by score (highest to lowest)
5. Show the class average score

## Requirements
- Use any programming language you are comfortable with.
- Include clear instructions to run your solution.
- Add at least 3 test cases to validate your logic.
- Handle invalid input gracefully.

## Input/Output Example
- Add: `Asha 85`
- Add: `Ravi 92`
- Add: `Nina 78`
- Output (sorted): `Ravi 92, Asha 85, Nina 78`
- Average: `85.0`

## Submission
- Share your source code.
- Share test cases and their output.
- Add a short note (2–4 lines) explaining your approach.

## Evaluation Criteria
- Correctness
- Code quality and readability
- Test coverage
- Input validation
